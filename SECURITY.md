# Seguridad y privacidad

Jauria ejecuta herramientas locales sobre repositorios elegidos por el usuario. Revisa las instrucciones, permisos y cambios antes de autorizar acciones. Un relevo conserva contexto; no concede permisos nuevos ni constituye aceptación del trabajo.

No adjuntes tokens, credenciales, bases SQLite, perfiles de proveedores, prompts privados, transcripciones ni logs sin revisar. El estado local y las credenciales deben permanecer fuera de Git. La exclusión por `.gitignore` es preventiva; no elimina información ya incorporada al historial.

Para reportar una vulnerabilidad, contacta de forma privada con el propietario del repositorio mediante un canal acordado. Incluye versión, impacto y una reproducción mínima en un repositorio desechable con datos ficticios. No publiques secretos ni detalles explotables en issues. No hay un plazo de respuesta o soporte de seguridad establecido para este candidato.
