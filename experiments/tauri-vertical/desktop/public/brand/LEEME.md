# Jauría — kit de marca

## Logos
| Archivo | Uso |
|---|---|
| `jauria-mascota-claro` / `-oscuro` (.svg, .png) | Logo principal (mascota + nombre): README, web, presentaciones |
| `jauria-mascota-simbolo` (.svg, .png) | Solo la mascota, fondo transparente: avatar, stickers |
| `jauria-logo-horizontal-claro` / `-oscuro` / `-transparente` | Barra de navegación, encabezados, firma |
| `jauria-icono-app.svg`, `jauria-icono-app-1024.png` | Ícono de la app (macOS / Windows / Linux) |
| `jauria-favicon.ico`, `jauria-favicon-32.png`, `-64.png` | Pestaña del navegador |

Los SVG tienen el texto convertido a trazos: no necesitan la fuente instalada.

## Carpetas
- `manual/` — manual de marca en PDF y PNG.
- `tokens/` — colores y fuentes en CSS (`jauria-colores.css`) y JSON (`jauria-tokens.json`).
- `fuentes/` — Bricolage Grotesque, Inter y JetBrains Mono en .woff2, con sus licencias (SIL OFL, uso libre incluso comercial).

## Reglas rápidas
- Espacio libre alrededor del logo: el alto de la oreja doblada.
- Tamaños mínimos: ícono 16 px · horizontal 96 px de ancho · mascota 64 px de alto.
- Los ojos siempre son el prompt `>_` en ámbar `#F0B323`.
- No enderezar la oreja doblada, no estirar, no añadir sombras ni degradados.
- El ámbar no va como texto sobre fondo blanco.
